## HydraDB compatibility correction

HydraDB v0.1.1 can split its Bolt manifest response across TCP events. With
`neo4j-driver` 6.2, the observed negotiation path tried to parse the incomplete
first event and reached an out-of-range native `Buffer` read. HydraTrace pins
`neo4j-driver` 5.27.0 for this server pairing; it uses the compatible classic
Bolt negotiation path.

Scalar graph operations are serialized over Bolt. Complete-path reads use the
lossless HTTP NDJSON query surface with the configured causal or strong
consistency, and the adapter fails closed on missing terminal summaries or
truncation. The local restart smoke wrapper allows 180 seconds because a cold
HydraDB read can exceed the former 60-second wrapper even when the operation is
healthy.
